### 件 1:T2.2 余量——STOP 判停接线

**runner.py(四处镜像改动)**:`_STOP_RX`(仿 `_HANDOFF_RX`:27)/`extract_stop`(仿 :60)/`AgentResult.stop_text`(:88)/`harvest_stop()`(:267,同"从后向前扫"策略)/`to_result()`(:277)接线。

**driver.py(终止判定区 642-657 插入)**:收割→观察者之后:

- 有 `<Stop>` 但无效 → `ev.emit("stop_invalid")`,继续下一轮。

**验收**:单测(达成引现存 F-xxx→停 / 引证不存在→不停+事件 / 测尽+理由→停);mock runner 两轮集成;**usc-fresh 真账本收割回放**(FINDINGS+FACTS 拷临时目录→收割→断言入图数;skipif 不存在)。

### 件 2:T2.3——观察者七类行解析器(新 `src/observer_harvest.py`)

`apply_observer_lines(bb, lines, *, round, rejected_ids) -> {counts, rejects}`,机械执行 schema §7:

| 行 | 处置 |
|---|---|
| `verdict` | 硬拒 id **不受理**(件 4 前置);proposed→confirmed/dismissed+severity/reason(不变量 3 由 board 兜底);confirmed 不可翻案自动被拒 |
| `edge same_root` | **正主规则(拍板2=B)**:`primary`∈{src,dst} → 正主=primary;缺失/非法 → 回退先到优先(confirmed 最早;schema 只定到这,round 最早→dst 是我们的并列补位)。边=非正主→正主(**primary=src 时翻转成 dst→src**);非正主机械 dismissed("并入正主 D-xxx";已 confirmed 则保持+警告) |
| `edge supersedes` | add_edge+旧 fact→superseded(board 兜底仅 confirmed 可迁) |
| `comment` | update_node(intent.comment) |
| `intent` | create_node(open, observer)+有 `from` 则 add_edge(spawns) |
| `intel` | add_intel(必填;缺失记警告不阻塞) |
| `guide` | **bookkeeping.guide={round,text}**(P5 观察者产出;T4.1 注入 stdin) |

- 非法行 → rejects 列表 → driver 追加 `.observer/OBSERVER.rejects` + `observer_parse_fail` 事件;
- 驱动点:治理后读 `root/.observer/OBSERVER`,**不存在即跳过**(P5 前不会存在);
- **报告晋升**:confirmed 报告 `.auto\reports\` → `reports\`(writeback 新函数)。批 2 交付函数+单测,**真实激活依赖批 3**(T3.2/T3.3 报告制度+目录)。

**验收**:七类行逐类单测+正主回退两例+隔离区+硬拒不受理+晋升 e2e(tmp 目录)。

### 件 3:T2.4——STATE.md 六节终态+一轮两刷
