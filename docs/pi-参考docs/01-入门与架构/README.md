## 核心概念导读

### 1. 极简主义设计 (Minimalism & Zero-bloat)
Pi 的核心设计原则是**纯粹、快速、可控**：
- 核心代码库极度轻量，无过度封装与冗余抽象；
- 终端优先（Terminal-First）的高性能响应与渲染；
- 对外部模型提供统一、标准化的 API 抽象层。

### 2. Agent Loop 运行循环
Pi 在执行任务时遵循严格的循环生命周期：
1. **用户输入**：通过终端输入提示词或执行斜杠命令；
2. **上下文装配**：收集系统提示词、会话历史、上下文文件并进行必要压缩；
3. **LLM 推理**：向大语言模型发起请求，支持流式输出与思考过程（Thinking/Reasoning）；
4. **工具调用分发**：解析模型输出中的工具调用指令，并在安全沙箱内执行相应工具；
5. **结果反馈**：将工具执行结果作为 Tool Result 追加到会话流中；
6. **循环终止判断**：若模型继续发起工具调用则继续循环，否则完成本轮交互并等待用户输入。

### 3. 会话树与可追溯性
Pi 的每个交互记录都持久化为 JSONL 文件，支持树状分支、任意回溯（Checkout）、分支合并与总结压缩。
