## 口径记录（2026-10-21 讨论，S2/P4 背景注）

1. **闸机多域名真实目标**：scope 本就是 host 数组（B 靶即双字面量），真实渗透多域名/多主机的处置口径 = **起跑前把 engagement 授权 host 全量预列进 task.json scope + 跑动中发现关联资产走 `at1 scope-add` 热扩权（S2 剧本正验此链）**。明确**不做**"自动认定关联=放行"——scope 是授权边界，"看起来有关联"必须人判：误杀是烦，误放是越权，代价不对称。P4 ask 通道会把人判环节做得更顺（worker ask 一次、操作员放行一次）。
