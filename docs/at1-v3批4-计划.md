### G1 治理链完整性修复（门禁 · 代码）
- **改动**（对应 §3.1 A-E）：
  - **A 删守门员扫描器 → 无状态目录页**：
    - 删 `_dir_diff` / `offsets["files_seen"]` / 纳秒指纹整套（带状态的记账是 bug 根源）
    - driver 主循环内维护**内存级**上轮清单（跨轮存活、重启清零、**不落盘不进 offsets**），与当轮目录对比算出 `new_or_changed` 标记——标记仅供参考，**不承担正确性责任**
    - 任务单新增 `worker_output` 字段：**全量目录页**（path/dir/bytes/mtime/new_or_changed），**全量列出含旧文件**（不做取舍），**禁止含文件内容**（零快照红线）
    - "哪些要审"由观察者对照图（evidence 指针做差集）自行判断——手册写明"目录页是索引不是指令"
  - **B 观察者挂 guard（终版裁决 09-19）**：
    - 教育层：OBSERVER-MANUAL 明令——**禁止直接编辑 `.at1/blackboard.json`**（写图只走判断书，直接改文件=绕过全部校验）；**不改动 worker 产出原文**（实测产生的证据写进 `.observer/` 自己的工作台）
    - 检测层：`run_once` 的 AgentTask 挂 `on_fact` → 复用同款 Guard（worker 同规则）→ `guard_violation` 事件加 `role: observer` 标记。**只记录不阻断**（guard 本就无 OS 强制力，与"本阶段不做行为限制"裁决一致）
    - **运行期自愈如实入档**（不当防线用）：driver 全程持有图内存态，轮末 `bb.save()` 用内存态整体覆盖文件——会话中途被直接改的图会被冲掉（篡改留不住）；仅 run 末次 save 之后/Edit 的窗口会留存。故检测事件仍必要（要"知道"）
    - 单测：观察者 Write `.at1/` → guard_violation（role=observer）；读图不告警
  - **C 计量接住**：`run_once` 返回值写进 `observer_session_end`（tokens/cost/turns/stop_reason，重试会话各记一条）
  - **D set_state 不再覆盖 note（裁决①）**：非 blocked 迁移**不动 note**（note=add_intent 创建时的方向说明书，永不改）——迁移理由写 `comment` 批注槽；blocked 照旧写 `blocked_reason`
  - **E 协议放宽对齐（裁决 E-1）**：`reason` 仅 **blocked 必填**（=可检验条件，丢了没法解锁）；其余状态选填（填了进 comment，不填不拒）——contracts §2 表同步
  - **F 提交机制（终版裁决 09-19）：`submit-judgment` 受理/入图两阶段**：
    - 新增 CLI `python -m src submit-judgment`：读判断书 → 与执行器**同一套校验代码**逐条过 → 全部合法打印"提交成功（N 条已受理）"退出码 0；有坏条逐条报错、退出码 1
    - 观察者退出条件=**提交成功**（prompt+手册写明：没成功不许退；有报错就地改了再提交，幂等无害）
    - 入图时机=driver 轮末（执行器再跑同一套校验，结果必然一致）——**图唯一写手仍是 driver 侧执行器**，规避双写覆盖陷阱（driver 内存态轮末覆盖磁盘，提交命令若直接入图会被冲掉）
    - **R8 兜底升级（Cairn conclude-fallback 模式）**：观察者未成功提交即退出 → **resume 同 session**（runner 的 session_id）+ 把校验错误精确回喂（"第 2 条 severity 非法，请修正后重新提交"）——观察者带完整上下文修，不再无记忆重跑；一次机会，仍失败 → 告警
    - **重放安全**：修正后的判断书重新提交时，已入图条目由查重/幂等吸收（add_fact 撞键返回已有 id、set_state 同态、add_edge 声明优先）
- **连带删除**：`files_seen` 相关测试改造；`_dir_diff` 用例替换为"任务单含无状态目录页、无 offsets 残留"断言
- **验收**（单测七连）：①任务单目录页含路径/大小/时间、**无文件内容**（零快照）②观察者失败轮**无持久化记账残留**（无 offsets["files_seen"]）③观察者 Write `.at1/` → guard_violation（role=observer）、读图不告警 ④observer_session_end 含 tokens/cost ⑤set_state 不覆盖 note、迁移理由进 comment ⑥submit-judgment：合法判断书→受理成功退出码 0；缺 reason 的 blocked→拒收退出码 1 ⑦重放安全：同一判断书提交两次不重复入图
