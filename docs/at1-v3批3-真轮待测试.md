> **术语**：接口在，server 不在——判断书（OBSERVER.json）=接口请求体，执行器=服务端，本表=协议文档，文件+进程退出=批交付传输。观察者不主动"请求"：写完退出即提交，controller 转交执行器。
> **状态语义**：图唯一写手=观察者，入图即终态（落笔前已审计），proposed 待审状态消亡；"confirmed 不可翻案"保留——跨轮翻案只能加新节点替代，不能改旧节点。

| operation | 字段 | 执行器行为 |
|---|---|---|
| add_fact | summary, evidence, endpoint?, ref? | 建 confirmed fact；hash 撞键→返回已有 id（幂等）；ref 指向方向/发现→自动连边；summary 带"目标画像："前缀→自动换代旧画像（机械 supersede） |
| add_finding | summary, report(必填), severity, reason, result?(默认 confirmed), endpoint?, ref? | 发现登记：唯一来源=worker 写的 findings/ 文件；result=dismissed→阴性视图（"别再试"）；noreport 命中不受理 |
| add_intent | goal, note, ref? | 开新方向；ref=来源线索（自动 sources 边） |
| set_state | id, state(open/in_progress/done/blocked), reason | 方向生命周期；blocked 必带可检验条件（A11） |
| add_edge | src, rel(六动词), dst, note | 显式连边。**边的三来源**：worker 声明（自由文本"配合 X/与 Y 组合"，观察者翻译落笔）/观察者主动组合（note 写组合逻辑=链式思路记录）/机械兜底（ref+同 endpoint auto_link） |

**已裁操作与去向**：
- ~~verdict~~ → add_finding 的 result 字段承接（发现登记即裁决；误报=dismissed 进阴性）
- ~~annotate / set_guide~~ → 非图信息全去 STATE.md：引导=STATE.md 固定节（开头"## 下轮建议"），controller 机械抽取该节进【引导】块（stdin 三块形态不动，A17）；批注/进度叙事=STATE.md 正文
- ~~supersede~~ → 机械规则（add_fact 画像前缀自动换代），不需观察者手工调

判断书纪律（进 schema 与 OBSERVER-MANUAL 双处）：长数据放文件指针不塞 JSON（Cairn 规则）；不重复图中已有信息（写增量）；每条 operation 的 evidence/report 对应 worker 产出的真实文件。

## 12.2 F6 讨论修订记录（2026-09-19 逐条讨论收敛，均已并入上文）

1. **回执删除，退出即信号**：判断书写完→进程退出→controller 跑执行器。"写完忘说回执/说了没写完"的两阶段缝隙是伪问题——controller 本就等进程退出，无需带内信号；执行器只认文件可解析性。
2. **verdict 并入 add_finding**：finding 的登记即裁决（result 字段），独立 verdict 操作删除——初版"只留 verdict"的方案在"图内无节点可裁"处有漏洞（finding 节点本不存在，verdict 无从作用），终版见 §12.1。
3. **计数守恒删除**：防"漏看"机制不值得建——材料永远在盘上，worker 下轮读得到自己的 FINDINGS.md，漏一条可自愈；硬校验还会冤枉"看了但无可记"的合法处置。
4. **空产出重试保留**：防的是进程白跑（判断书不存在/解析失败/operations 空→重试拉起一次→再失败告警），不是防漏看。
5. **STATE.md 定位修正**：worker 开工优先读图本体；STATE.md=配合读的进度总结+思路建议（非限制口吻），并入 F4 措辞。
6. **观察者可实测验证**：存疑发现可发真实请求复核（v3 T5.1"纸面+实测重放"质检的继承），验证结论进判断书。
7. **操作集 8→5 收敛**：verdict 删（add_finding 的 result 承接）；annotate/set_guide 删（STATE.md 承接，引导=STATE.md 固定节抽取）；supersede 删（画像前缀机械换代）；add_edge 恢复（组合是事后随时发生的——单 fact 不致命、组合成链；ref 只盖创建时单一指向）。
8. **proposed 状态消亡**：图唯一写手=观察者，入图即终态；无生产者的状态不保留；"不可翻案"锁换形式保留（替代节点）。
9. **worker 写盘文件夹化**：FINDINGS.md/FACTS.md 大账本取消——Write 工具整文件覆盖姿势下"追加纪律"反人体工学（冲掉账本史=diff 全乱且 guard 不管）；一条一文件=最顺手姿势且天然原子；diff=目录新增文件对比（比字节 offsets 皮实）；reports/ 并入 findings/（发现文件即报告本体）。
10. **约束模式的答案**："约束只有 prompt"不成立——prompt 管 整齐路径（顺手姿势=守规矩姿势），观察者任务单=全量扫描本轮新增文件兜底（放错位置不丢，只是不整洁）。

执行顺序：F1→F2（图地基）→ F3→F4→F5（工作区与退役）→ F6→F7（观察者核心）→ F8。

成本注记：观察者改 -p agent 后每轮多一次 agent 会话，deepseek-v4-flash 计价重估进复跑对照。
