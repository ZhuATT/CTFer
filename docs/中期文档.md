## 1. 系统总览

### 1.1 形态：一个控制器 + 两类会话进程（cwd 都是 engagement 根——单层化，无 .auto/）

```
python -m src run <engagement> [--budget 秒,默认不设] [--rounds N] [--stop-on-first-confirmed]
   │
   ├─ 控制器（Python 常驻进程，零 LLM token，全事件落账）
   │    driver    主循环：配方0 播种 → 渲染 stdin → spawn worker → 目录页盘点 →
   │              spawn 观察者 → 执行器入图 → STATE 兜底 → 判停
   │    runner    进程桥：spawn `claude -p`、流解析、续跑梯子（支持外部 resume_session_id）、
   │              树杀、双阈值呆滞告警
   │    board v3  图黑板：三原子+四视图+Stop 校验（.at1/blackboard.json；无 proposed 态）
   │    observer  观察者 -p 同构会话（-p spawn/任务单/判断书读取/模型通道，deepseek 默认）
   │    observer_harvest  判断书执行器：五操作校验+入图+receipts/rejects
   │    submit.py 观察者受理 CLI：判断书校验全过→SUBMITTED 标记（不入图）
   │    guard     实时检测（worker 与观察者都挂）：scope 越界/禁区写/自毁——只记不拦
   │    noreport  代码检察官：reject=形状即现象（硬拒清单）；suspect=公诉意见（进任务单）
   │    stoploss  连击止损；harvest  只剩 diff_new_lines（hints 增量读）
   │    events    事件流（白名单制 JSONL）；scaffold  workdir 展开（单层）
   │
   ├─ worker 会话（每轮一个 claude -p，glm-5.3-flash，cwd=engagement 根）
   │    写盘面 = facts/ findings/ evidence/（一条一文件，格式自由）
   │    读权限 = 图本体 .at1/blackboard.json（禁写可读）
   │
   ├─ 观察者会话（每轮一个 claude -p，deepseek-v4-flash 默认可配，cwd=同根）
   │    工作台 = .observer/（worker 禁入）；产出 = 判断书 OBSERVER.json + STATE.md + prior-intel-draft
   │
   └─ 磁盘即真相：控制器无常驻状态，杀掉 run 重跑 = 续跑
```

**信任模型（批3fix 版）**：

| 主体 | 写什么 | 读什么 | 说明 |
|---|---|---|---|
| worker | facts//findings//evidence/（自由格式） | 图本体（禁写可读）+ STATE.md | 内容生产者；**永不写图**（guard 禁写 .at1/） |
| 观察者 | 判断书（经执行器入图）+ STATE.md + prior-intel-draft + .observer/ 工作台 | worker 产出原文 + 图本体 + 可实测验证 | **图唯一写手**（经执行器）；不改动 worker 原文 |
| controller | 不产生内容；只做：spawn/kill、执行器调用的宿主、事件流、STATE 兜底计数 | — | 图写入的唯一执行者=执行器代码 |

### 1.2 一次 run 的完整时序（伪代码级）

```
run_engagement(engagement_root):
  fail-fast：engagement.json（target/goal/hint）+ notes/prior-intel.md 非空
  bb = Blackboard(.at1/blackboard.json)          ← v2 遗形自动归档
  播种 target/goal/hint/scope → 配方0：画像 fact ×1（直落终态）+ prior-intel 指针
  scaffold.expand：根目录预建 facts//findings//evidence/ + CLAUDE.md + .mcp.json + src标准/
  ev = 事件流；guard；stoploss
  [run_start / board_legacy_archived / resume / scope_missing]
  dry_run? → prompt + STATE 兜底 + bb.save → return

  preflight（claude CLI / playwright）→ 失败拒启
  盯梢线程（0.5s 轮询 state/CONTROL）

  while True:
    CONTROL（stop/pause/directive）+ hints.jsonl 偏移收割 → 运行提示
    预算检查
    prompt = 三块（【引导】=STATE.md"下轮建议"节抽取 + 【运行提示】 + 【简报】）
    spawn worker（时间盒 1800s；计量含 total_cost_usd）
    目录页盘点 _inventory_page：facts//findings//evidence/ 全量清单
      + new_or_changed 标记（内存级对比，不落盘）
    noreport 前置：rejects（硬拒清单）+ precheck_hints（公诉意见）
    Handoff 落簿记（读者=观察者，进任务单）
    stoploss 记录
    观察者会话：
      copy 手册/协议 → 清上轮判断书/标记
      run_once（deepseek，时间盒 1800s）：读产出+读图+实测验证 → 写 OBSERVER.json
        （工具调用过 guard，role=observer 事件）
      退出 → 读判断书：
        缺失/坏/空 → resume 同 session 精确回喂一次 → 仍失败 → exhausted 告警
      提交成功 → 执行器逐条校验入图（receipts/rejects）→ observer_applied
    STATE.md：观察者写了就用；没写 → 兜底极简计数
    bb.save() → STATE 兜底
    worker <Stop> 终判（引证护栏）→ stoploss → stop_on_first_confirmed → 循环

  收尾：收盯梢线程 / bb.save / run_end
```

## 2. 开工：engagement.json → 黑板

### 2.1 委托书字段

| 字段 | 必填 | 语义 | 去向 |
|---|---|---|---|
| target | **是** | 打谁 | 手册 {target} 槽 + guard |
| goal | **是** | 完成标准，一句可判定 | bookkeeping.goal → `<Stop>达成` 锚点 |
| hint | 字段必填（值可空） | 开工指示 | 手册 {hint} 槽 |
| scope.allow/deny | 可选 | 授权边界 | guard；缺失不拒启+scope_missing |
| skills_src | 否 | 方法论库 | 根/.claude/skills/ |

- 知识不进委托书：背景情报写 `notes/prior-intel.md`（**拒启件**，必须非空）、须知写 hint、标准写 goal。

## 5. 轮末：目录页 → 观察者 → 执行器（批3fix 新链）

### 5.1 无状态目录页（`_inventory_page`）

facts//findings//evidence/ 全量盘点：path/dir/bytes/new_or_changed（内存级上轮指纹对比）。**零持久化**（不进 offsets）——观察者失败也不存在"漏看"问题（下轮照样全量列出）。

### 5.2 noreport 前置（T2.6 语义保留）

- **reject**（形状即现象：端点即 .map/裸 instance-id/169.254）→ 硬拒清单 → 执行器对命中路径的 add_finding **拒不受理**
- **suspect**（CORS/安全头/版本指纹/内网 IP）→ **公诉意见进任务单 `precheck_hints`**（批4 新出口；提示观察者重点核实，非结论）
- 实害豁免先行：summary 声明影响/证据含凭证形状/手机号 → 永远放行

### 5.3 判断书提交（submit-judgment CLI）

观察者审计完 → 运行 `submit.py`（任务单给全路径命令）→ 校验全过：写 `.observer/SUBMITTED` 标记（打印"提交成功"）→ 观察者退出 → driver 轮末读判断书 → 执行器逐条校验入图。**有坏条：逐条报错退出码 1，观察者就地修正重新提交**（幂等：查重撞键返回已有 id）。

## 6. 观察者（-p 同构，已实现）

### 6.1 会话形态

claude -p（deepseek-v4-flash 默认，可配 glm），时间盒 1800s（`AT1_OBSERVER_TIMEBOX_S`），cwd=engagement 根，工作台 `.observer/`（worker 禁入）。stdin=**最小任务单**（轮次/goal/worker_output 目录页/precheck_hints/Handoff/读图与协议路径——零快照，细节自己读盘）。工具调用过 guard（role=observer 事件）。

### 6.2 判定方法论（OBSERVER-MANUAL §3，源=v2 JUDGE_PROMPT 迁移）

- **第零步绝对不报**（硬否决+但书）：开放重定向/CORS/Self-XSS/sourcemap/版本指纹/安全头/rate limit/裸 instance-id/内网 IP/元数据端点/容器 RCE 无逃逸/外部 SSRF——现象作为链载体打到实际影响时继续
- **四步影响框架**：影响是什么→是否设计内行为（查请求者身份字段）→影响量级（凭证/≥3元组 PII/单字段/非敏感）→利用条件是否归零（受害者操作/内网过滤）
- **suspect 公诉意见**=参考非结论
- **落点**：`add_finding` 的 result（confirmed/dismissed）+ severity；**验不了的→不入图**（图=二值门）

### 6.3 产出

- 判断书 `.observer/OBSERVER.json`（五操作：add_fact/add_finding/add_intent/set_state/add_edge）
- STATE.md（进度总结+"## 下轮建议"固定节；下轮【引导】来源）
- notes/prior-intel-draft.md（收尾导出）
