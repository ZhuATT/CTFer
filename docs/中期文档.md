## 1. 系统总览

### 1.1 形态：一个控制器 + 两类会话进程 + 一辆托管浏览器（cwd 都是 engagement 根）

```
python -m src run <engagement> [--budget 秒,默认不设] [--rounds N(相对本次 run)] [--no-observer] [--stop-on-first-confirmed]
   │
   ├─ 控制器（Python 常驻进程，零 LLM token，全事件落账）
   │    driver    主循环：配方0 播种 → 浏览器池启动 → 渲染 stdin → spawn worker → 目录页盘点 →
   │              spawn 观察者 → 执行器入图 → STATE 兜底 → 判停；停机三道门（S1）+ phase 账本（S5）
   │    runner    进程桥：spawn `claude -p`、流解析、瞬态续跑梯子（外部硬杀复活/喊停真死——
   │              controller_kill 死因标签区分）、树杀、双阈值呆滞告警
   │    browser   浏览器池（playwright 批）：driver detached 托管每 engagement 独立 Chrome
   │              （start/ensure/shutdown 三拍；状态=.at1/browser.json；MCP 经 env 附着为客人）
   │    board v3  图黑板：三原子+四视图+Stop 校验（.at1/blackboard.json；无 proposed 态）
   │    observer  观察者 -p 同构会话（任务单/判断书读取/模型通道，可配）
   │    observer_harvest  判断书执行器：五操作校验+入图+receipts/rejects
   │    submit.py 观察者受理 CLI：判断书校验全过→SUBMITTED 标记（不入图）
   │    guard     检测记录（worker 与观察者都挂）：scope 越界/禁区写/自毁——**只记不拦（P-9 摄像头）**
   │    noreport  代码检察官：reject=形状即现象（硬拒清单）；suspect=公诉意见（进任务单）
   │    stoploss  连击止损（--rounds 相对语义，F1）；harvest  只剩 diff_new_lines（hints 增量读）
   │    events    事件流（白名单制 JSONL）；scaffold  workdir 展开（单层）+ .mcp.json 渲染（钉版）
   │    runlock   所有权锁（S3：单实例，进程死内核自动放锁）
   │    phase     账本（S5：working/auditing + session_id——断点续接触发器）
   │
   ├─ worker 会话（每轮一个 claude -p，glm-5.3-flash，cwd=engagement 根）
   │    写盘面 = facts/ findings/ evidence/（一条一文件，格式自由）
   │    读权限 = 图本体 .at1/blackboard.json（禁写可读）
   │    浏览器 = 经 MCP 附着托管 Chrome（env 注入 CDP 端点——有意共享，F4 语义）
   │
   ├─ 观察者会话（每轮一个 claude -p，模型可配，cwd=同根）
   │    工作台 = .observer/（worker 禁入）；产出 = 判断书 OBSERVER.json + STATE.md + prior-intel-draft
   │
   ├─ 托管 Chrome（run 级常驻，engagement 专属 profile，detached——不在任何会话进程树内）
   │    轮间保活（状态跨轮）→ run_end 按 KEEP 收尸（默认杀 / AT1_BROWSER_KEEP=1 留守）
   │
   └─ 磁盘即真相：控制器无常驻状态，杀掉 run 重跑 = 断点续接（能续则续，续不了则新开）
```

**信任模型（F4 修正版）**：

| 主体 | 写什么 | 读什么 | 说明 |
|---|---|---|---|
| worker | facts//findings//evidence/（自由格式） | 图本体（禁写可读）+ STATE.md + storage-state.json | 内容生产者；**永不写图**；**可全权操作本 engagement 浏览器**（含 CDP 端点，env 可见——同信任域有意共享，2026-10-13 拍板） |
| 观察者 | 判断书（经执行器入图）+ STATE.md + prior-intel-draft + .observer/ 工作台 | worker 产出原文 + 图本体 + 可实测验证 | **图唯一写手**（经执行器）；不改动 worker 原文；env 继承亦可附着浏览器 |
| controller | 不产生内容；只做：spawn/kill、浏览器池托管、执行器宿主、事件流、STATE 兜底计数 | — | 图写入的唯一执行者=执行器代码 |
| guard | **只记录不阻断**（事后拍，P-9 摄像头）——scope 越界/禁区写/自毁全记账，命令照样执行 | — | 它是审计回放源，**不是防线**（2026-10-13 措辞对齐：全部"拦"改"记"） |

```

  ev = 事件流；guard；stoploss（base_round=启动时簿记轮号——F1 相对语义）
  [run_start / board_legacy_archived / resume(轮号>0 且图非空——F2 修正) / scope_missing]
  dry_run? → prompt + STATE 兜底 + bb.save → return

  preflight（claude CLI / playwright 钉版 / chrome exe 在场）→ 失败拒启
  浏览器池启动（B2）：BrowserHandle.start → 成功则 env 注 CDP 端点；skip/no-exe 则主动清 env

  try:                                    ← F 批 try/finally：异常路径 Chrome 也收得到
    while True:
      stop 二次读（续修批竞态闭合）+ hints.jsonl 偏移收割 → 【人工指示】

        死因=controller_kill 则终态不复活；外部硬杀/瞬态故障 → 续跑梯子复活同轮
```

## 7. 停机与判停

**停机三道门（S1）**：`control-stop(W)`（worker 阶段）/`control-stop(O)`（观察者阶段，判断书未入图即作废）/`control-stop(D)`（边界检得）。配套：S2 观察者出生登记 proc_ref（杀活会话不杀尸体）；S4 stop 返回=实例必已死（轮询 runlock，`AT1_STOP_WAIT_S` 默认 30s）；干净收尾清 phase 账，control-stop 有意留残留=续接触发器（S12）。

## 9. 浏览器池（playwright 批，B1-B6 竣工+实机验收全过）

### 9.1 所有权与三拍

**根因**：-p 模型下挂在 MCP 进程树上的状态活不过一轮。浏览器所有权归 driver（唯一活过整个 engagement 的进程）：detached 拉 Chrome（engagement 专属 profile，不在任何会话树内，树杀够不着）→ MCP 经 `PLAYWRIGHT_MCP_CDP_ENDPOINT` 附着为客人 → 轮末 worker 树死不掉它。

- `start()`：读 `.at1/browser.json`——pid 活+CDP 通+headless 一致 → 复用（browser_reuse）；否则**先杀旧进程**（假死实例占 profile 锁）再拉新（browser_start）。headless 与 flag 不一致 → **flag 优先杀旧重起**
- `ensure()`：每轮 spawn 前探活（/json/version 2s，无代理 opener），失败同款杀旧拉新（browser_relaunch）；彻底起不来置 dead 不空转
- `shutdown(keep)`：keep=1 留守（账供下次复用）；keep=0 `taskkill /T /F`+删账（browser_exit）

### 9.2 语义边界（实机钉死）

| 语义 | 实机结论 |
|---|---|
| browser_close | 只关本轮 MCP 自建页，**进程不死**、旧标签存活；关最后一张页→Chrome 无窗即退→ensure 兜底 |
| env 穿透 | claude -p→stdio MCP 继承 ✓（渲染退路作废）；CDP 模式下模板 --executable-path 被忽略 |
| 外部硬杀 vs 喊停 | taskkill worker→梯子复活同轮重新附着；src stop→真死。controller_kill 标签是分界 |
| JSESSIONID 跨实例 | 该站 Set-Cookie 持久化→浏览器重启登录态仍在；真掉线则 B5 重导舞步兜底 |
| KEEP 语义 | 默认 0=run_end 杀+删账；=1 留守；**紧急人工强杀连坐属预期**（detached 只断控制台不断父子） |
| 残账清理 | pid 已死的账→`browser_start orphan-dead` 干净重拉（E5b 实证） |

### 9.3 配置位

`AT1_BROWSER_EXE`（显式设置即权威，指错→skip 走 MCP fallback）/`AT1_BROWSER_HEADLESS`（默认 0 有头）/`AT1_BROWSER_KEEP`（默认 0 收尸）/`PLAYWRIGHT_MCP_CDP_ENDPOINT`（driver 注入，不暴露给用户）。`@playwright/mcp` 钉 **0.0.83**（模板+preflight 同常量，漂移即红）。

## 14. 施工坑档案（批1 → playwright → 10-13 累计）

1. **双重抽取**：runner 已剥 Stop 标签，driver 用 `validate_stop_content` 管裸内容
2. **events 白名单**：新事件必须登记 EVENT_TYPES 否则 emit ValueError；**纯 mock 假 ev 测不出漏登记——真 Emitter 冒烟是必备验收件**
3. **相对路径**：tests 指向仓库外是 `../../` 两级
4. **语义变更必须同步 mock**：否则旧测试真 spawn 烧 API
5. **收割幂等计数**：create_node 去重返回旧 id，判断"真新建"要比对前后节点数
6. **汇编围栏**：四反引号；**嵌入内容与 scaffolding 逐字锁**（改手册必须两边同改，锁③a/③c）
7. **bash 内联 python 处理含反引号 markdown → 误建空文件**（禁用，改 Write/Edit 或落 .py）
8. **--rounds 绝对轮号事故（F1）**：持久轮号引入后老判定没跟——绝对/相对语义在续跑场景必分家；新写判定先问"这个数字是本次的还是账本的"
9. **判定顺序（F2）**：播种发生在"图非空"判定之前 → 判定条件要用**跨 run 持久的信号**（轮号），不用被本 run 改写的信号（图）
10. **from-import 打桩位置**：`from .x import f` 是导入期绑定——patch 要打在使用方命名空间（driver_mod.find_exe），不是源模块
11. **测试隔离浏览器池**：driver 全流程测试 autouse 桩 `_NoopBrowser`（否则每条测试真弹 Chrome）；browser 专项在用例内覆盖回真类/脚本替身
12. **npm 浮动版本**：依赖行为（env var/工具语义）的包必须钉版+桌面确认后再升（@playwright/mcp 0.0.83）
13. **代理环境**：本机 HTTP_PROXY 类 env 会让 urllib 探活/直连全部假阴——探活用无代理 opener；教育网目标必须走代理（worker 走 env、Chrome 走系统代理，两者都要在）
