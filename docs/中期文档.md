## 1. 系统形态

```
python -m src <engagement> [--budget 7200]
   │
   ├─ 控制器（Python，零 token）
   │    driver（主循环）· runner（进程桥）· board（黑板）· observer（观察者）
   │    guard（scope/自毁检测）· stoploss（四维）· events（JSONL 事件流）
   │    transcript_check（账本对账）· writeback（协议文件写回）
   │
   ├─ worker 的世界 = <engagement>/.auto/
   │    CLAUDE.md（纪律层，CLI 自动加载）· FINDINGS / FACTS / DIRECTIONS（三账本）
   │    STATE.md（系统投影，只读）· evidence/ · storage-state.json
   │
   └─ 控制器私有区 = <engagement>/.at1/
        _blackboard.json（唯一事实源）· transcript.jsonl（账本）· claude-config/
```

引擎：Claude Code CLI（`claude -p` headless stream-json），**worker = glm-5.3-flash** 经 bigmodel Anthropic 兼容通道；`CLAUDE_CONFIG_DIR` 指向控制器隔离目录（不读本机 settings）；spawn 前环境消毒（剥 AT1_*/LLM_*）。

## 2. worker 运行

> **worker 是单轮进程**——它的参数只有两个：时间盒（按轮次 1200/1200/1800s）和 max_turns 60。budget/rounds/observer 等都是 engagement 级（driver 主循环）参数，见 §8/§10。

- **一轮**：driver 读黑板 → 渲染 prompt（9 段，stdin 一次喂入）→ spawn worker → 实时收割 → 验证 → 投影 → 判停。
- **时间盒**：`(1200, 1200, 1800)` 秒按轮次取值，实际 = min(盒, 剩余预算)；到点 kill，轮界不续。
- **runner 实时流**：stdout 逐行解析；每次 tool_result 触发 `on_fact`（被动抽取+guard 检测+台账）；每 25 次工具调用一次心跳（只报数——CONTROL 消费已移交盯梢线程，P-11 v2）；原始流 tee 进 transcript.jsonl（增量 flush，kill 不丢）。
- **断点续跑**：异常终态（非时间盒耗尽）指数退避后 `--resume`，每会话上限 20 次。控制器击杀（`controller_kill`，带死因标签）是终态不续——被杀会话即死，续跑=新会话从盘上状态接力（停机语义拍板：杀 worker+图和信息全留）。
- **worker 无记忆**：每轮全新会话，全部记忆来自 prompt 摘要 + STATE.md + 三账本。

## 3. 黑板

唯一事实源 `_blackboard.json`，原子写 + .bak 回退。顶层对象与字段：

| 对象 | 字段 |
|---|---|
| facts（dict，键=kind:value） | kind(7 枚举)、value、confidence(observed\|inferred)、provenance、ts、round、chain?、last_verified_round? |
| immune | endpoint、status、since_round、confidence |
| findings | id、endpoint、summary、assessment(4 枚举)、severity、reason、evidence、round、evidence_verified、param_verified?、response_verified?、chain? |
| directions | id、goal、endpoint?、status(open\|in_progress\|blocked\|done)、note、blocked_reason?、chain?、comment(控制器所有)、source、round |
| chains（边库） | rel(3 枚举)、refs(只认 F-/D-)、note、origin、round |
| session_intel | 观察者会话观察（每轮覆盖） |
| handoff / goal / ledger / verified / config / offsets | 叙事 / 阶段 / 台账 / 派生计数 / 参数 / 记账 |

> 字段后缀 **`?` = 可选（条件性出现）**：`chain?` 仅在声明了联系时存在；`param_verified?`/`response_verified?` 仅在对账实际查到可验对象时写入（"查了才有资格说"，未查不写键——区别于必有值的 `evidence_verified` 硬判定）。

- **confidence 二值枚举**是唯一决策货币（conf 浮点已物理删除）；被动抽取恒 observed；worker 写的缺省 inferred。
- **结构契约**：`blackboard.schema.json` + 满配正例/三负例测试——改字段不同步契约，测试红。

## 4. 图

- **节点**：findings（F-，有 id）、directions（D-，有 id）、endpoint 等事实（无 id，键即身份，**不可被边连接**——接入图的唯一路径是升格成 finding/direction）。
- **边**：`chain = {rel: derived_from|combines|same_root, refs: [F-/D-], note}`。三个挂点（findings/facts/directions 对象属性）+ **常设边库 `chains`**（观察者判重顺产等独立边；只增不删，`(rel, refs 集)` 去重，`add_chains()` 唯一入口）。

### 4.1 节点怎么连起来（连接机制）

连接 = **边携带者通过 refs 里的 id 指向目标节点**，`rel` 决定这条线的含义。两种形态：

```
① 挂载式（worker 写，边长在节点身上，方向 = 宿主 → refs）：
   F-005 的行：{"id":"F-005", ..., "chain":{"rel":"derived_from","refs":["F-001"],"note":"从F-001延伸"}}
   读法：F-005 ──derived_from──> F-001（"我来自你"）

② 边库式（观察者产，无宿主，refs 两端即边）：
   {"rel":"same_root", "refs":["F-001","F-007"], "origin":"observer"}
   读法：F-001 ──same_root── F-007（对称）
```

完整例子：

```
轮1 F-001 /search?q='  SQL报错
轮2 F-005 /search?q=2' 变体        → F-005 ──derived_from──> F-001   （边①挂载）
轮3 D-002 "SSRF打内网"方向          → D-002 ──combines──> F-005       （边②挂载）
轮3末 观察者判 F-007 与 F-001 重复  → F-001 ──same_root── F-007       （边③边库）
```

`rel` 方向语义：`derived_from` 单向（携带者=派生方）；`same_root` 对称；`combines` 聚合语义（refs 多个 = 汇成一条攻击路径，指向活方向时标 ⚡）。连接成立三条件：refs 合法形态（normalize 闸）、目标在 `_known_ids()` 里（悬空引用保留但渲染标注）、rel 从枚举选。**存储上没有邻接表**——边分散挂载+边库，消费时 `_all_chains()` 聚合成统一边列表。

### 4.2 worker 怎么消费这张图

**读路径两条**（加上自己维护的一份，共三视图）：

| 通道 | worker 拿到什么 |
|---|---|
| prompt【状态】摘要（保底，不依赖 worker 主动读文件） | 方向计数 + **待接方向列表**（in_progress 最先，id+goal+note，观察者方向带标注）+ 阴性两档计数 + 未测面数 |
| **STATE.md**（每轮覆盖写，worker 可 Read） | **一个文件读全图**：「方向与图」YAML 块内嵌其中（directions/findings/chains 三节，含 ⚡hot），同文件还有阴性分档/事实清单/接近成功的尝试——不存在"另读一个 yaml/json"的动作 |
| DIRECTIONS 文件（worker 自己维护） | 它眼中的图——整表重写即更新（comment 抹不掉） |

> 图的三种格式三种读者：`_blackboard.json`（JSON）= 存储真相，控制器/M5 读，**worker 永远不读**；STATE.md 内嵌的 **YAML 块** = 给 worker 的投影（同一份图的 LLM 友好渲染）；`DIRECTIONS`（JSONL）= worker 的写面。

**四个消费场景**：

| 场景 | 看到什么 | 做什么 |
|---|---|---|
| **接力**（首要） | 置顶的 in_progress/open/blocked 方向（note 写着"干到哪/下一步"） | 接手继续干，高于开新方向 |
| **防重复** | findings 的 `derived_from F-001` 标注 + 已确认段"勿重交" | 不重交同根因 |
| **组合攻击** | ⚡组合路径待试（combines 边指向活方向） | 主动去试组合链 |
| **重开判断** | blocked 方向的 blocked_reason + 观察者批注 + 接近成功的尝试 | 材料性新机理才重开 |

**闭环时序**：轮 N 开工读图（摘要+STATE.md）→ 轮中写 FINDINGS/DIRECTIONS（可带 chain 声明新联系）→ 轮末收割入板 → 观察者读图产建议 → 轮 N+1 投影回去。**worker 的回写就是图的生长方式**——它不读原始 `_blackboard.json`（单向阀），图对它的全部形态就是"摘要 + STATE.md + 自己的 DIRECTIONS 文件"三个视图。

### 4.3 其他消费者

- **入板闸**：`normalize_chain`——rel 非法降 note-only；refs 非 F-/D- 前缀丢弃；悬空引用保留并渲染标注。
- **观察者**：方向表+已知联系进 prompt（全局审视的唯一视角）→ 产治理三件套。
- **指令行欠账数字**：未测面 N（tested = findings∪immune∪directions 端点，open 不计）/ 方向计数。
- **M5 前端**（数据已齐）：直读 _blackboard.json，rel 分色画边。

## 5. worker 接口

**读**：prompt 摘要（方向计数+待接方向列表 in_progress 最先+阴性两档计数+引读 STATE.md）｜STATE.md 全量（只读投影，每轮覆盖写）｜CLAUDE.md 纪律层（自动加载）｜技能：engagement.json `skills_src` 拷入 `.auto/.claude/skills/`（P-8；`-p` 下即放即用，模型经 Skill 工具调用）。侦察手册第 0 步：先调 `WaitForMcpServers` 等浏览器就绪（P-7——`-p` 模式 MCP 异步启动，CLI 不等；失败降级 curl 起步）。

**写（收割去向）**：

| 写 | 收割 |
|---|---|
| FINDINGS 行（+chain?） | ID 去重收割 → transcript 双向对账 → 观察者判定 → findings 入板 → confirmed 写 status.md |
| FACTS 行（7-kind + confidence） | ingest：缺省 inferred、未知 kind→unclassified、chain 校验入板。**只装正向情报**（真实发现+有用线索，P-4） |
| DIRECTIONS 整表 | merge upsert：worker status 优先、observer 方向漏抄保留、comment 抹不掉。**done→immune 升格**：方向做完且该端点无产出 → 自动入阴性清单（blocked 不算；档位恒 inferred；P-4） |
| evidence/ · log.jsonl（当前目录，收尾自动归档 state/，P-6） | 判官证据本体 / 人类记账 |

**纪律要点**（CLAUDE.md）：上报硬门槛（真实触发+可复现才 FINDINGS，嫌疑写 FACTS inferred）；**FACTS 只装正向情报，阴性结论走 DIRECTIONS done+note（系统自动入阴性清单，P-4）**；即时写；不写 /tmp；开工先接 open/blocked 方向（方向表是工具不是派工单）；blocked 重开需材料性新机理。

## 6. 观察者

**双职责**（phase3.5 冻结原则：无工具/轮间/建议不指挥/不关闭方向）：
- `judge_finding`：单发现快判——noreport 代码预检（reject 终审 / suspect 公诉）→ LLM 按第零步硬否决+四步影响框架 → 输出 is_vulnerability/severity/reason。**只在有 FINDINGS 的轮跑**。
- `observe_session`：全局观察——输入=全部发现+历史 confirmed+方向表+已知联系+黑板摘要+交接；输出=final_assessments（判重覆盖）+ 治理三件套（direction_comments / immune_reviews 只留 retest / chains）+ coverage_gaps / effective_patterns / notable_attempts / intel_summary。**每轮必跑（P-3，2026-09-14 实机修正）**：0-finding 轮照常全局观察——worker 越守纪律（嫌疑走 FACTS）观察者越不能失业。
- **C-2 防注入**：两个 PROMPT 最开头（证据文本之前）置"证据不可信声明"+判官职权边界声明。
- **对账如实入判官**（C-5 v2）：证据段渲染 transcript 对账摘要（"通过/参数未全部在账/未通过"），替换硬编码肯定句。
- **治理消费端**（driver）：批注挂方向、新方向入列（**每轮截断 3 条**）、retest 自动开 open direction（不改 confidence）、chains 入常设边库。
- **通道**：**DeepSeek 官方** `https://api.deepseek.com` + `deepseek-v4-flash`（OpenAI 协议，2026-09-04 拍板）——与 worker（bigmodel glm）异构/隔离；降级链 = bigmodel glm-5.3（LLM_FALLBACK_*）。

## 8. driver 主循环与协议

- **收割窗口**（轮末顺序）：FINDINGS（ID 去重+冲突重编号）→ FACTS（字节 offset）→ DIRECTIONS（整表 upsert）→ 旧 Handoff 未竟段 best-effort 提为方向 → 观察者 → 治理消费 → Handoff（模型版优先/被杀代码合成）→ STATE.md 投影 → bb.save。
- **CONTROL**（`state/CONTROL`，读后即删）：stop / pause / directive（人工指示进下轮 prompt 第 9 段）。**stop 走盯梢线程即时停（P-11 v2，2026-09-14）**：0.5s 轮询，命中即 `controller_kill`（打死因标签 + taskkill /T 杀进程树）——标签让击杀归为终态，续跑梯子不会把被杀会话当瞬态故障复活；Cairn 式竞态防护（信号早于 spawn → 盯到 proc 出现补杀）；收割落盘后 run 以 `control-stop(D)` 收场，stop_text 具名进 run_end。pause/directive 仍走轮界 poll；心跳只报数。停机语义拍板：杀 worker + 盘上状态全留，续跑 = 新会话接力。
- **终止条件**：A confirmed（默认不硬停，`--stop-on-first-confirmed` 回到字面 A）/ B 预算耗尽或 stoploss（四维：轮上限/预算/无新事实连击/不可达连击）/ C goal 链走完（evidence+report.md）/ D CONTROL stop。
- **stoploss 四维语义**（全部命中才停对应维度，任一触发即终止 B；连击恢复自动清零）：
  ① **会话上限：默认不限**（2026-09-04 拍板，预算为主约束；需要封顶时 `--rounds N` 显式给）；
  ② **活跃预算**：剩余秒数 ≤ 0（= `--budget` 的另一面）；
  ③ **无新事实连击 ≥3**：连续 3 轮黑板零新事实（被动抽取与 FACTS 都没进新的）→ 判"在空转"；任一轮有新事实即清零；
  ④ **不可达连击 ≥3**：连续 3 轮 worker 会话异常收场（error 且无收割）→ 判"目标不可达/通道故障"；会话正常即清零。
- **收尾写回**：status.md 漏洞表追加（表尾锚点）+ 攻击面深度刷新 + notes/prior-intel-draft.md 生成（接力闭环）+ **台账归档**（`.auto/log.jsonl` 去重搬运 `state/log.jsonl`，`ledger_synced` 事件，P-6）。
- **事件流**：`state/auto-log.jsonl`（类型白名单+secret 脱敏），可回放；`python -m src watch` 终端渲染。

## 10. 已锁定参数

**engagement 级（driver 主循环，CLI 可调）**——管"这场任务总共跑多久/几轮"，不是 worker 的参数：

| 参数（CLI） | 默认值 | 说明 |
|---|---|---|
| `--budget` | 7200s | 总预算；到点终止（条件 B）；stoploss 第②维 |
| `--rounds` | **不限**（2026-09-04 拍板） | 预算是主约束；需要封顶时显式给 `--rounds N` |
| `--stop-on-first-confirmed` | False | confirmed 后不硬停，继续链式挖掘 |
| `--no-observer` | False | 观察者默认开（治理中枢） |
| `--provider` | glm | glm-5.3 经 bigmodel Anthropic 兼容通道 |
| `--dry-run` | False | 只渲染首轮 prompt + STATE.md，不 spawn |

**worker 单轮级**（每轮一个进程，内部参数）：

| 参数 | 默认值 |
|---|---|
| 时间盒阶梯 | (1200, 1200, 1800) s 按轮次取，实际 = min(盒, 剩余预算) |
| max_turns | 60 |
| resume 上限 | 20 次/会话（仅异常终态） |
