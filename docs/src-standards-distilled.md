# SRC 判读标准汇编（七家顶级厂商全量蒸馏）

> 原料：`src标准/txt/{阿里云,菜鸟,小米,美团,腾讯,京东,字节跳动}.txt`（规范化单篇详见 `src标准/*.md`）。
> 用途：门 2 CLASS_REQS 判定树的权威素材 + 考题来源 + Worker/Planner 定级标尺。
> 蒸馏原则：跨厂商共识 → 硬规则；单厂商特有 → 标注来源按需采用。

## 0. 跨厂商硬共识（七家全部出现 → 直接进绝对不报）

- Self-XSS / 仅本地解析的 XSS（PDF XSS 等）
- 无敏感操作的 CSRF（收藏、加购物车、非重要资料修改、订阅等）
- 内网 IP / 域名 / 路径 / 版本号信息泄漏（无凭据价值的均不收）
- 纯属猜测、无法重现、无有效 PoC 的理论扫描报告
- 账户存在性枚举、未达标短信/邮件轰炸（如横向轰炸、轮循手机号）
- 不涉及安全的产品 Bug（乱码/样式/功能故障/应用版本兼容性）
- 电商业务中子账号越权主账号（京东/字节电商明确暂不收）
- 容器/沙箱预期内代码执行（无逃逸路径不收）

## 1. 敏感数据分级与量级门槛（七家共识矩阵）

| 级别 | 定义与包含内容（三元组 = 任意三字段组合） | 权威出处 |
|---|---|---|
| **极度** | 法定证件无水印照、核心账号密码对、人脸/指纹生物识别 | 菜鸟 / 阿里 |
| **重要** | ① 个人三元组：姓名+手机+地址+银行卡等 ≥3 元组；<br>② 业务凭证：AK/SK、可直接登录 CVM/核心DB 的账号密码、K8s 集群凭证；<br>③ 订单三元组：买家姓名/手机/地址/商品/价格订单三元组；<br>④ 公司内部数据：员工姓名/花名/部门/手机/职级三元组 | 菜鸟 / 小米 / 美团 / 腾讯 / 字节 / 京东 |
| **次重要** | 账号名/邮箱/生日/性别 ≥3 元组；非核心业务订单信息、商品浏览与收藏记录 | 菜鸟 / 阿里 |
| **其他** | 设备信息、会员等级、地域分布、仓储物流运营信息（按低危接收或驳回） | 菜鸟 / 京东 |

**量级门槛分布**：
- **巨量 (>10万条 / >100万条)**：小米 >10万条成立；美团/腾讯严重门槛为 **>100万条**（美团 50W~100W 需二次特审）。
- **大量 (>1万条 / ≥5000条)**：小米/腾讯 >1万条；美团高危门槛为 **≥3 字段 + 包含 1 个人标识 + ≥5000条**（不足 3 字段或不足 5000 条降中危）。
- **少量 (>1000条)**：小米/阿里中危门槛。
- **极少量 (<100条 / 边缘系统)**：降为低危或忽略。

## 2. 分类判读边界（→ CLASS_REQS 素材）

**越权读（idor_read）**
- 收：越权获取用户/商户敏感信息（字段组合+量级定档）；越权查询订单号等业务数据 = 中危（美团/京东）。
- 拒：**无敏感信息的越权访问**（美团/字节无效区）；影响用户量极小的降级（菜鸟§五3）。
- 限：测试读取数据**严禁超过 5 条**（京东红线），禁止批量拖库。

**越权写（idor_write）**
- 高：无前置条件的水平越权敏感操作——改重要信息、订单敏感操作、核心配置修改（美团/阿里/腾讯）。
- 低：不涉核心数据或少量非重要信息的增删改（阿里低4/菜鸟低4）。
- 红线：**严禁使用线上真实用户账号测试增删改**（京东红线），必须使用自己的测试账号。

**垂直越权（authbypass）**
- 管理功能垂直越权（不影响核心数据） = **低**（阿里/菜鸟）；
- 垂直越权敏感操作（修改重要信息、配置、权限提升） = **中**（美团/腾讯）。

**信息泄露（infoleak）**
- 严重/高危：AK/SK、可登录生产 CVM 凭据、K8s 集群凭证、账密对、数据库连接串。
- 低危：phpinfo、SVN/Git 信息、调试报错、仅库名字段名的本地注入（小米低/阿里低/京东低）。
- 无效：路径/内网 IP/无意义报错（共识）——**铁律：非凭据类一律不收**。
- **红线**：**发现 AK/SK 或集群凭据严禁自行深入业务验证危害**（腾讯/字节铁律），必须立即提单由审核验证。

**SQL 注入（sqli_error/diff）**
- 严重：核心 DB、海量敏感多元组（阿里/小米/腾讯/美团）。
- 中危：非核心 DB、少量或无重要数据（阿里中2/京东中）。
- 验证红线：
  - 腾讯：白帽子仅读取当前表第一个字段的前两个字符佐证；
  - 京东：仅限手工执行 `select db_name()` 读取库名，**严禁读取表内敏感数据**；
  - 菜鸟：接 WAF 的须证明可手工注出当前表 1 条实际数据（严禁使用 SQLMap 自动化工具）。

**SSRF（ssrf）**
- 高危：可达核心网络并完全回显或图片回显（阿里高3/腾讯高7/小米高）。
- 中危：无回显但能直接访问内网服务（美团中/腾讯中3/京东中）。
- **无效：仅 dnslog 回连、无任何内网信息**（小米忽略区原文/腾讯规范）；内网完全过滤同理。
- **官方指定验证桩**：
  - 腾讯 TSRC：`http://tst.woa.com/flag.html` / `http://9.138.237.216/flag.html`
  - 京东 JSRC：`http://ssrf.jd.local/c3f3f53c12674acdc9855f47b85299f0.html`
  - 小米 MiSRC：`ssrf.dun.mi.com`

**XXE / LFI / 任意文件读写**
- 高危：全站 COS 对象存储任意读写覆盖（腾讯）、读到核心敏感文件/源码外带成功。
- 低/拒：任意文件读但仅非敏感文件且无法进一步利用（阿里中3）；公开静态文件、`jcloud-oss` / `jcloudcs.com` 文件上传不算漏洞（京东 V9.1）。

**XSS**
- 高危：核心页面（首页/商品/门店/邮箱）无交互存储型；影响客服、管理员并可获取权限（阿里/美团/腾讯）。
- 中危：一般业务页面存储型；不受浏览器策略限制的 DOM-XSS（小米/美团）。
- 低危：反射型（各家低）。
- 无效：Self-XSS、PDF XSS、小众浏览器限定（共识）。
- **投递链是分档核心**：受害者可触达 + 输出点可执行。

**客户端漏洞交互分档（移动端核心共识）**
- **严重 (Critical)**：**0-Click 无交互**，在 APP 进程内执行任意代码/命令，或直接接管登录账号（字节/美团/腾讯）。
- **高危 (High)**：**1-Click 仅需一次点击**，在 APP 进程内执行代码或接管账号（字节/美团）。
- **中/低危**：需多步交互、复杂社工诱导、或依赖用户特殊本地配合。

**业务逻辑 / 竞争（logic_race）**
- 收：条件竞争、优惠券使用限制绕过、认证流程绕过（美团中/腾讯中）。
- **不收：拉新活动、无法实际套现的优惠券**（阿里严重1/高1原文）；纯用户猜测。
- 量级：可无限重复刷取核心资源→高；大金额少量或小金额大量→中。

## 3. 去重与合并（各家统一策略）

- 同一功能越权增删改查只确认 1 个；相似接口（getDetail/getList）只收 1 个。
- 同一根因（同一过滤函数/全局中间件/同一组件缺陷）只确认第 1 个。
- 同库 SQL 注入确认前 3 个（第 1 个正常，后 2 个降级确认）。
- 0-day 按实际业务影响确认，无实际影响案例不收。
- 相互依赖的多个漏洞，按共同影响下达到的**最大危害定级**（如弱口令到命令执行按命令执行算）。

## 4. 证据要求与测试红线

- JS fuzz 出的 API 越权须提供**接口提取、请求构造、遍历过程**完整证明，否则降级（美团）。
- 报告须含原始 HTTP 数据包（raw）+ 清晰截图；缺可复现 PoC = 无效。
- **强制报备红线**：反弹 Shell、容器逃逸、文件上传必须提前报备（字节跳动）；未经授权严禁内网横向、扫描与后门植入。
- **URL 跳转验证**：腾讯必须证明可直接跳转到指定钓鱼域名 `http://www.qq.com_521_qq_diao_yu_wangzhan_789.com` 无提示无中转。

## 5. 大模型与 AI 产品收录规则（腾讯/字节/美团/小米四家共识）

> **适用范围**：腾讯元宝/混元、字节豆包/扣子 (coze.cn)、美团 LongCat、各业务 AI Agent。

* **坚决不收（非信息安全漏洞）**：
  1. 提示词越狱（Jailbreak，如 DAN 类提示词绕过）；
  2. 提示词泄露（Prompt Leak）；
  3. 模型输出违规内容（违规营销、恶意文本、敏感言论，均属于业务内容安全范畴，走客服反馈通道）；
  4. 模型幻觉利用（诱导大模型模拟计算机终端并执行伪命令）；
  5. 沙箱环境内正常代码/命令执行（属于产品预期核心功能）。
* **正常收录与定级（必须具备实质信息安全危害）**：
  1. **沙箱逃逸**：成功逃逸至宿主机/物理机层面（需证明实际权限）；
  2. **内网穿透**：通过沙箱环境穿透至企业内网（可通过 SSRF 连通性测试桩实证）；
  3. **数据泄露**：越权访问他人私有对话记录、获取核心底层训练集或核心服务高权限凭证；
  4. **宿主提权**：容器/沙箱逃逸后提权至 root 或集群管理权限。
