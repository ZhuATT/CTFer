### P1 🔴 锚定形态传导缺口（工具描述教错形态）——✅ 已按修法 A 修复

- **证据**：`src/tools/submit.ts:47/98`——endpoint 参数描述示例是**路径形态**（`/jsxsd/foo.do`、`/static/app.js.map`）；而 `anchorFact`（`src/assets.ts`）需 **host 承载形态**（裸 host / host:port / URL）才能归一化。路径形态 → 空 host 异常 → catch → **静默返回 undefined，fact 照常入图、锚不落、零账面痕迹**。
- **后果（不修）**：worker 照工具描述示例提交路径 → 锚定链空转 → S1 步 2 断言（anchors 落行）必挂，整轮 LLM 白烧。
- **修法**：
  - **A（首选，≈2 行 + 0 测试改动）**：工具描述示例改 host 承载形态（如 `127.0.0.1:8790/api/orders/8823`）；可选 worker prompt 补一句"endpoint 写完整 host[:port]/path"。
  - B（≈20 行 + 测试）：anchorFact 纯路径结合 scope host 拼装——引入"猜 host"语义，非必要不上。
  - **✅ A 落地记录（2026-10-21）**：两处工具描述改 host 承载示例 +「别写纯路径（纯路径锚不到资产）」；worker prompt 完成定义第 3 步补形态句；**附加加固**（超出拍板最小面 +3 行）：`normalizeEndpoint` 对纯路径形态抛「Endpoint 缺少 host」——修前实证路径形态不是抛异常而是落 `host=""` 垃圾资产行，现在交 anchorFact catch 静默吞（旁路不阻塞不变），不再污染 assets 表。测试：`test/assets.test.ts` 纯路径守卫用例。
- **备注**：与 P2 同根（形态假设没对齐），**A 修完后 P2 立刻显形**（worker 会提交 host:port 形态 → 落进 P2 描述的分裂），两项应一起拍板。（已一并修，见下。）

### P2 🔴 scope 裸 host 与锚定 host:port 必然分裂（三子系统形态假设不一致）——✅ 已按修法 A 修复

- **证据**（2026-10-21 guard 核实）：
  - `guard.ts extractHosts`（URL_RX 端口组非捕获）+ `hosts.has(h)` **纯 host 比对**——scope.hosts 必须写**裸 host**，写 `127.0.0.1:8790` 会被 guard **误拦**（抽出 `127.0.0.1` ≠ Set 里的 `127.0.0.1:8790`）；
  - `resolveScopeHosts` 对裸 host 建 **port=null** 资产；
  - worker endpoint 天然 host:port/URL 形态 → **port=8790** 资产——同一目标两资产，锚定与 coverage **永不相交**。本地靶 8790 是非默认端口，"协议默认端口豁免"救不了。
- **后果（不修）**：P1 单修也到不了位——锚会落，但落在 port=8790 资产上；scope 资产（port=null）恒 untouched、anchored 恒 0、简报锚定 facts 恒空 → S1 步 3/4 断言必挂。
- **修法**：
  - **A（推荐，≈30 行 + 测试）**：**查询层放宽**——`coverageQuery` 的 untouched/anchored 判定与简报锚定匹配改 **host 级**（忽略 port）；assets 表保留端口精度（审计不受损）。
  - B（≈50 行，动资产不变量）：归一化层合并——裸 host 视为伞资产，findOrCreateAsset 层做父子关联。
  - C（**被 guard block**）：scope 写法统一 host:port——须连改 guard 语义，不推荐。
  - **✅ A 落地记录（2026-10-21）**：三处查询放宽——`coverageQuery` anchored/untouched 判定、`listAssetsInScope` anchor_count（planner 视角与 coverage 口径一致）、`briefing.ts` 简报锚定匹配（EXISTS 同 host 任意 port 资产）——全部 host 级；他 task 的锚照旧不计入；assets 表两行（port=null + port=8790）保留端口精度；guard 语义未动。测试：`test/assets.test.ts` 分裂场景回归用例（裸 host scope 被 host:port 锚覆盖/他 task 不跨计/异 host 不误伤）+ `test/p3-integration.test.ts` 全链剧本断言更新（B 视角 anchor_count=1、anchored=1、untouched 空）。旧行为（锚=资产级精确匹配）在 `test/assets.test.ts` 原有用例（裸 host 锚裸 host）下依旧全绿——host 级是放宽不是替换。
