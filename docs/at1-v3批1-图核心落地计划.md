### 2.2 三原子操作(schema §6.1,controller 独占)

```python
create_node(kind, payload, *, endpoint="global", origin, round) -> str   # 按 kind 发号 D-###/F-###/T-###
update_node(id, *, state=None, payload_patch=None, comment=None) -> bool # 状态迁移/批注
add_edge(src, rel, dst, *, origin, note="", round=0) -> bool             # (src,rel,dst) 去重,重复=False
```

六不变量的 board 级机械强制(可单测):
1. 发号冲突 → 重编号 `F-R{round}-{orig}`(v2 机制沿用);
2. 节点/边无删除 API(一切消亡=状态);
3. **verdict 仅作用于 proposed**:finding 现态≠proposed 时 update_node(state=confirmed/dismissed) 返回 False(不变量 3 的机械执行点);
4. 声明优先:add_edge 不覆盖已存在 (src,rel,dst);
5. 节点去重键 (kind, endpoint, 归一化内容)——value/summary/goal strip+lower+截 120;
6. 每次写带 round+origin(参数必填)。

### 2.3 四派生视图(schema §5,零存储现算)

```python
negative_view() -> list[dict]     # intent(done ∧ 无 yields 出边, 死因=note) ∪ finding(dismissed, 死因=reason)
endpoint_groups() -> dict[ep, list[node]]
lineage_view() -> dict[id, {"parents": [指入边源], "yields": [指出边目标]}]
untested_surface() -> list[ep]    # 出现过的 endpoint − 有 intent/finding 覆盖的 endpoint
```

### 2.4 goal 与 Stop(T1.5)

```python
set_goal(text) -> None                        # bookkeeping.goal = {"text", "updated_round"}(A24:goal-set CLI 的底层,CLI 壳批 2 接)
parse_stop(text) -> dict | None               # 提取 <Stop>;达成理由须引现存 F-xxx → {"refs":[...], "reason":...};无引证/引证不存在 → None(无效)
```

- stage 机/check_goal 四段出口/`_advance`/`TERMINAL_C` 文件判定**全删**;判停三角=预算(driver 已有)+人工停(P-11 已有)+worker 有效 Stop(parse_stop 供 T2.2 收割)。
