# 阿里云安全应急响应中心 (ALISRC) 漏洞评分标准

> **适用范围**：阿里云自身产品、云上业务、官网及核心基础设施相关漏洞判定与定级。  
> **判读原则**：按实际造成的业务危害与利用影响定级，中间过程不单独定级。零信息丢失，纯结构化 Markdown 汇编。

---

# 一、严重漏洞 (Critical)

### 1. 业务逻辑与资金安全类
* **海量资损 / 刷钱**：黑产正在利用的能实际造成海量资损的漏洞，或能直接刷钱的漏洞。
  * **【明确不包含】**：拉新活动、云资源的后付费使用、部分无法实际套现的优惠券等。

### 2. 服务端与基础设施权限类
* **核心网络控制**：获取任意一台核心网络服务器的权限（可使用官方工具判断是否属于核心网络）。
* **直接下线应用**：能直接下线/关停生产环境核心应用的漏洞。
* **网络基础设施瘫痪**：攻击网络或网络设备造成控制或瘫痪系统，使得阿里云关键业务功能不可用或被监听。
* **海量服务器控制**：通过未授权访问后台等方式获得海量服务器的控制权限，且包含业务敏感信息。

### 3. 数据安全与越权类
* **核心账号敏感数据查询**：通过注入或接口泄漏等方式，进行核心账号体系敏感信息多元组任意查询，或获取海量重要敏感信息多元组。
* **核心数据篡改**：海量用户身份信息等业务核心功能核心数据的无遍历限制修改、查询。
* **对象存储篡改**：核心敏感业务数据对象存储篡改，如能造成供应链攻击，或业务面临重大风险。
* **批量身份伪造**：交易及聊天软件场景的批量任意伪造身份并发送任意内容信息。

### 4. 账号与设计缺陷类
* **主账号体系接管**：主账号体系的任意账号登录，或主账号体系任意撞库且证明能直接登录的问题。
* **官网首页篡改**：直接能修改业务 `www` 首页关键位置信息的漏洞。

### 5. 云安全与虚拟化逃逸类
* **容器/沙箱/虚拟化逃逸**：利用普通用户的 ECS、沙箱、Docker 等权限，提升到宿主机/集群的权限。
* **跨租户数据库提权**：利用普通的数据库权限提升，获取到实例中其他用户数据库内容的权限。

### 6. APP 与客户端类
* **远程无条件 RCE**：邮箱和聊天 APP/客户端的远程无条件代码执行。

# 二、高危漏洞 (High)

### 1. 业务逻辑与资金安全类
* **大量资损**：黑产已经在利用的能实际造成大量资损，或潜在可造成海量资损的漏洞。
  * **【明确不包含】**：拉新、云资源的后付费使用、部分无法实际套现的优惠券等。

### 2. 服务端与应用安全类
* **生产服务器权限**：获取任意生产应用云上业务的服务器权限。
* **任意文件读取/利用**：可读取到服务器上敏感文件或能进一步深度利用。
* **敏感内存泄漏/登录利用**：可通过如心脏滴血等类似漏洞随机获取到主账号体系的敏感信息，且证明可以利用该信息进行账号登录或其他敏感操作。
* **核心功能拒绝服务**：可通过简单手段造成重要业务核心功能 DOS（拒绝服务）。
* **其他危害扩大**：其他可造成进一步扩大攻击的服务端类问题。

### 3. 网络与 SSRF 类
* **进核心网络代理**：网络层 HTTP/Socks/TCP 代理可进入核心网络。
* **核心网络回显 SSRF**：可达核心网络，并可完全回显或通过图片等形式回显的 SSRF。

### 4. 数据安全与存储类
* **大量敏感数据 SQL 注入/泄露**：通过注入或接口泄漏等方式可获取大量敏感信息多元组，如核心功能核心数据的 SQL 注入。
* **大量身份信息篡改**：大量用户身份信息等业务核心功能核心数据的无遍历限制修改、查询。
* **数据存储控制**：能控制重要数据的存储设备，增删改查大量敏感信息。
* **大量服务器未授权**：通过未授权访问后台等方式获得大量服务器的控制权限，且包含业务敏感信息。

### 5. 账号体系与子站缺陷类
* **非主账号任意接管**：非业务主账号体系的任意密码重置、任意账号登录问题。
* **子站首页篡改**：直接能修改业务子站首页关键位置信息的缺陷。

### 6. 前端安全类
* **核心无交互存储 XSS**：核心功能处可影响所有用户的无交互存储 XSS，如阿里云产品详情主页。
* **传播型攻击**：蠕虫型 XSS、水坑攻击。
* **管理权限窃取 XSS**：影响客服、管理员并可获取到敏感数据，或可登录相应管理平台的 XSS。

### 7. APP 与客户端类
* **远程交互式 RCE**：通过扫码、访问 URL 等形式造成的远程 RCE，通过反编译、解密等进一步造成实际利用的问题。

### 8. 其他
* 其他可造成重要危害的问题。

# 三、中危漏洞 (Medium)

### 1. 业务逻辑与收费绕过类
* **主营收费刷取**：主营业务收费功能的大金额少量次数或小金额大量次数刷取。
* **非主营收费绕过**：非主营业务收费功能绕过付费，如业务上第三方应用多次免费使用、媒体资源绕过付费等。

### 2. 服务端与系统缺陷类
* **敏感信息泄露（无法深入利用）**：
  * 服务端配置文件、备份文件泄露；
  * 非核心业务数据库 SQL 注入；
  * 少量敏感数据或无重要敏感数据的 SQL 注入等普通敏感信息泄漏但无法进一步利用；
  * 心脏滴血获取到部分敏感信息但无法进一步利用。
* **文件读取与操作**：任意文件读取，或操作部分非敏感文件，或无法进一步利用的。
* **非核心拒绝服务**：造成非核心应用 DOS。
* **其他服务端危害**：其他有一定危害的服务端类问题。

### 3. 策略与验证绕过类
* **安全策略绕过**：手机安全锁绕过、二次验证绕过。
* **密码学缺陷**：加密算法破解获取敏感信息。

### 4. 数据查询、修改与存储类
* **数据查询**：通过注入及接口泄漏等方式可获取少量敏感信息或大量非敏感信息的。
* **核心资产微量修改**：少量会员认证身份、订单、服务器、ECS、资金等核心资产核心信息及不涉及上述信息的修改等。
* **一般存储控制**：能控制一般应用的存储，增删改查部分业务信息等。
* **后台未授权**：通过未授权访问后台，含少量敏感信息。

### 5. 账号类问题
* **撞库爆破**：撞库类问题能爆破出数据但无法继续利用的。
* **高前置条件登录**：需要较高利用条件的核心账号体系任意账号登录（如 6 位验证码爆破）。
* **边缘业务登录**：用户量很少的业务自建账号体系任意账号登录。

### 6. 前端安全类
* **普通存储 XSS**：未在高危级别中定义的其他存储 XSS，如论坛帖子页面、分享页面等；无自然流量页面存储 XSS。
* **客户端 XSS**：客户端内触发的 XSS。
* **反射型 XSS**：各类反射型 XSS。
* **交互敏感操作 CSRF**：通过 CSRF 执行敏感操作。
* **跨域窃取**：JSONP 劫持敏感信息、CORS 劫持敏感信息。

### 7. APP 与客户端类
* **本地命令执行**：APP/客户端在本地环境下的命令执行漏洞。

# 四、低危漏洞 (Low)

### 1. 轻微信息泄漏
* PHPinfo 页面泄漏。
* 含有少量敏感信息的 SVN / 源码信息泄漏。
* 客户端应用本地 SQL 注入（仅泄漏数据库名称、字段名、cache 内容）。
* 敏感日志打印、常规配置信息泄露。

### 2. 交互限制 / 复杂度高 / 危害较小漏洞
* **管理功能垂直越权**（未造成敏感数据破坏）。
* Post 型 XSS、Postmessage 机制 XSS。
* 域内受限存储 XSS（只影响同一组织/租户内部的存储 XSS）。
* 非重要业务/非关键功能的 CSRF 操作。
* 需要预测复杂参数的 XSS / CSRF 等漏洞。

### 3. 轻微设计缺陷
* 对单个手机号的无限短信轰炸漏洞。
* URL 开放重定向跳转漏洞。
* 页面包含缺陷、CRLF 注入、HTML 文本注入。

### 4. 边缘功能越权
* 不涉及业务核心功能数据，或少量非重要敏感信息的增删改查越权问题。

---

# 五、无危害与不予收录 (Informational / Out of Scope)

> **奖励标准**：0 贡献值，0 安全币。

### 1. 不涉及安全问题的 Bug
* 产品功能逻辑缺陷、异常崩溃报错、网页乱码、样式混乱、静态文件目录遍历、应用版本兼容性等问题。

### 2. 无法直接利用或无实际危害的漏洞
* **无凭据信息泄漏**：路径信息泄漏、内网 IP 地址/内网域名泄漏、无意义的异常信息与报错。
* **前端无投递链**：Self-XSS、只有固定版本小众浏览器才能触发的 XSS。
* **无敏感操作**：无敏感操作的 CSRF（如收藏、添加购物车、订阅、非重要个人资料修改等）。
* **常规暴露**：管理后台地址泄漏、example 等默认 demo 页面未删除、无敏感信息的 SVN 泄露。
* **低频与无效轰炸**：邮件轰炸、轮循多个手机号的短信轰炸。
* **假性利用**：需要预测不可穷举参数的缺陷。

### 3. 缺乏实证的主观猜测
* 不能直接反映漏洞存在的其他问题，包括但不仅限于纯属用户猜测、无法提供有效复现 PoC 的问题。
