# 字节跳动安全响应中心 (ByteSRC) 安全报告处置规则与评分标准 (V6.0)

> **适用范围**：字节跳动中国区全线产品及服务（抖音、抖音电商、飞书、火山引擎、豆包、今日头条、懂车帝等）。  
> **判读原则**：以技术危害、利用链路完整性、业务资产系数与实际业务影响综合定级。零信息丢失，纯结构化 Markdown 汇编。

# 二、重大漏洞 (Critical+ 专项：最高 20 万元)

* **资产限定**：仅限于抖音、电商、飞书、财经、豆包、火山引擎六大业务的高系数核心资产。
* **判定标准**：
  * **集群/骨干权限突破**：核心云基础设施或大规模 Kubernetes 集群管理员权限泄露与提权漫游；
  * **千万级核心数据泄露**：导致千万级以上用户核心身份/敏感交易数据无门槛全量泄漏；
  * **0-Click 全网级传播**：在抖音或飞书生态内造成 0-Click 无交互全网蠕虫传播；
  * **严重资金资损**：支付结算链路可直接无限制刷取真实现金或等价资产。

---

# 三、严重漏洞 (Critical)

### 1. 服务端与系统核心控制
* **核心权限获取**：直接获取核心系统权限（命令执行 RCE、Webshell、反弹 Shell、核心容器逃逸、提权至 root 或集群管理员）。
* **核心 DB 注入**：核心业务数据库的 SQL 注入。
* **核心数据越权遍历**：无前置条件直接越权批量遍历核心敏感信息，或核心数据接口未授权泄露海量敏感信息。

### 2. 客户端 0-Click 任意控制
* **0-Click 客户端代码执行**：**无需任何用户交互 (0-Click)** 且无前置条件，即可在 APP 进程内执行任意代码/命令，或直接接管登录账号。

### 3. 业务严重逻辑缺陷
* 任意账号密码重置、资金与支付核心流程绕过、批量伪造他人身份发送消息或执行关键交易。

---

# 四、高危漏洞 (High)

### 1. 客户端 1-Click 权限获取
* **1-Click 客户端代码执行**：**仅需 1 次点击 (1-Click)** 交互，即可在 APP 内执行任意代码/命令，或接管登录账号。

### 2. 非核心 RCE 与应用权限
* 非核心业务或受限环境下的远程命令执行 (RCE)。
* 未授权访问敏感管理后台（具备实际线上业务操作与修改权限）。

### 3. 敏感数据泄露
* 源代码压缩包泄露、硬编码高权限密钥。
* 敏感配置信息大面积暴露。

### 4. 网络与前端漏洞
* **回显型 SSRF**：支持多协议探测内网并成功获取回显的 SSRF。
* **核心页面无交互 XSS**：核心业务页面的无交互存储型 XSS。

---

# 五、中危漏洞 (Medium)

### 1. 交互式前端与一般越权
* 存储型 XSS（一般业务页面）、涉及敏感操作的 CSRF 漏洞。
* 一般业务系统的水平/垂直越权操作。
* 需复杂交互或特定前置条件的客户端漏洞。

### 2. 受限注入与文件操作
* 非核心业务数据库 SQL 注入漏洞、少量敏感数据或无重要敏感数据的 SQL 注入。
* 任意文件读取（不可写）或部分非敏感文件读取。

### 3. 网络与逻辑缺陷
* 能访问内网但无回显的 SSRF 漏洞。
* 业务逻辑漏洞导致受限资损，或绕过高级功能使用限制。

---

# 六、低危漏洞 (Low)

### 1. 边缘前端
* 一般业务页面的反射型 XSS。
* 开放 URL 重定向跳转漏洞。

### 2. 轻微信息泄漏
* 调试信息泄露、Phpinfo 页面、无敏感信息的 SVN / Git 泄露、系统日志打印明文等。

### 3. 有限频控与本地 DoS
* 对单一手机号无限制的短信轰炸。
* 客户端应用本地拒绝服务漏洞（本地崩溃闪退）。

---

# 七、大模型与 AI 产品评级边界 (豆包 / 扣子 coze.cn)

1. **内容安全明确不收**：
   * 非信息安全漏洞引发的内容安全风险不予收录。
   * 与模型输入提示 (Prompt) 和响应内容直接相关的问题暂不收取（如越狱 Prompt、DAN 注入、模型生成违规营销话术或恶意代码）。
   * 诱导模型模拟终端环境执行伪命令（幻觉利用）不予收录。
2. **AI 服务风险收录边界**：
   * 非隐私数据泄露类风险（Prompt Leak 提示词泄露）暂不收取。
   * 用户自行发布的业务 Agent 及其关联插件所引发的安全漏洞不予收取。
3. **沙箱环境代码执行说明**：
   * 沙箱环境中的代码/命令执行属于产品预期功能，默认不作为漏洞。
   * **【有效漏洞判定条件】（满足其一即正常评分）**：
     1. 成功逃逸至宿主机 / 物理机层面；
     2. 获取到有效的宿主敏感信息或提权凭据；
     3. 证明已穿透至字节跳动内网环境（按 SSRF 连通性正常评级）。

---

# 八、忽略与不予收录清单 (硬否决项)

1. **网络层拒绝服务**：基于网络层面的拒绝服务攻击 (DoS / DDoS)、无法影响他人的本地 DoS。
2. **电商子账号越权**：电商业务中的**子账号越权主账号问题暂不收取**。
3. **无意义越权**：无任何意义或影响的越权（包括无法影响他人的越权）。
4. **外部客户资产**：火山引擎、BytePlus 外部客户自建系统的漏洞不收取。
5. **预期内设计**：符合业务预期的产品设计与功能流程。
6. **合规类问题**：隐私合规类问题暂不收取。

---

# 九、降级判定场景

1. 无法稳定复现的漏洞。
2. 需要复杂钓鱼或多步受害者交互的利用。
3. 影响范围极小（如只有几十个注册用户的新系统、旧系统只有少量数据）。
4. 对业务无实际影响的运维监控数据、测试数据泄露。
5. URL 跳转需要用户登录态，或必须注册固定域名才能跳转。
6. 利用条件极度苛刻（需要特殊权限、特殊复杂环境才能触发）。
7. 需要爆破难度较大的字段（如 6 位及以上随机验证码、密码等）。
8. 业务预期之内的资损问题或风险可控的问题。

# 十、测试红线与敏感行为强制报备

1. **敏感行为强制报备**：
   * **反弹 Shell、容器逃逸、文件上传** 等敏感操作，**必须提前通过官方报备问卷报备**（`https://bytedance.larkoffice.com/...`）；
   * **未经提前报备的测试结果一律不予漏洞奖励！**
2. **凭据严禁深入业务**：
   * 获取 AK/SK、Kubernetes 集群凭证（如 `kube-config`、`ServiceAccount`）后**必须直接提交报告**，由官方审核验证和确认影响范围及等级；
   * **严禁白帽子自行深入业务验证危害！** 翻找敏感凭据、增删改线上数据均属于违规禁止行为。
3. **测试素材合规**：
   * 严禁使用任何违规违法的文字、图片、视频作为测试素材或上传至平台。
