# 美团安全应急响应中心 (MTSRC) 漏洞评分标准

> **适用范围**：美团各业务线、大众点评、企业内网系统、移动端 APP、LongCat 大模型及业务 Agent。  
> **判读原则**：以技术危害、利用链路完整性、受影响数据量与字段属性综合定级。零信息丢失，纯结构化 Markdown 汇编。

---

# 一、个人敏感数据量级与判定矩阵

美团个人敏感数据定义须严格遵循：**3 个及以上字段组合，且至少包含 1 种个人标识信息**（如姓名、手机号、身份证号、银行卡号、位置轨迹等）。

| 危险等级 | 数据量级门槛 | 字段组合要求 | 典型场景与升降级机制 |
| :--- | :--- | :--- | :--- |
| **严重 (Critical)** | **> 100万条** | ≥3 字段 + 包含个人标识 | 核心 DB SQL 注入、无前置条件越权遍历；**[50W～100W条]** 且类型/影响显著可特批升严重 |
| **高危 (High)** | **≥ 5000条 且 < 50万条** | ≥3 字段 + 包含个人标识 | 越权遍历、敏感泄露；**[50W～100W条]** 属于高危临近严重档，由二次评定裁决 |
| **中危 (Medium)** | **< 5000条** 或 **字段不合规** | 字段不足 3 个 或 缺个人标识 | 只要数据量 <5000 条，或虽达标但字段不满足三元组要求，统一降为中危 |

> **【测试规范要求】**：若通过前端 JS Fuzz 获取后端 API 并构造请求实现越权访问，**必须提供完整的过程证明**（包括接口提取、参数构造、遍历截图），否则一律降级处理。

# 二、严重漏洞 (Critical)

### 1. 系统权限与内网突破
* **直接获取内网权限**：各类直接获取美团内网系统权限的漏洞，包括但不限于：远程命令执行 (RCE)、代码执行、植入 Webshell、SQL 注入获取系统权限、缓冲区溢出等（需参考官方 SSRF 测试说明，完成内网环境连通性证明）。

### 2. 核心数据泄露
* **核心 DB 注入**：可导致巨量美团敏感数据（资金明细、用户身份、订单信息）泄漏的核心数据库 SQL 注入风险。
* **巨量用户数据越权/泄露**：可获取巨量（**>100W 条**）美团用户个人敏感信息的信息泄漏风险，及无前置条件的越权遍历风险。

### 3. 账号体系接管 (0-Click)
* **0-Click 任意账号接管**：**无需用户任何形式的交互操作**，攻击者即可直接接管美团平台任意用户账号，获得账号完整控制权的漏洞。

### 4. 业务逻辑与资金安全
* **严重设计缺陷与流程缺陷**：
  * 任意金额支付漏洞；
  * 修改美团任意账号密码；
  * 完全控制美团平台任意账号。

---

# 三、高危漏洞 (High)

### 1. 服务端与应用安全
* **非核心 DB 注入**：可导致大量数据泄露的非核心数据库 SQL 注入风险。
* **管理后台未授权**：未授权访问管理后台、后台弱密码账号，可导致大量公司及业务敏感信息被泄露、篡改。
* **回显型 SSRF**：可回显 SSRF 漏洞，导致大量内部信息泄露或系统探测。
* **源码与凭证泄露**：源代码压缩包泄漏、硬编码密码等问题引起的公司及业务敏感信息泄露风险。

### 2. 用户与商户数据越权 (大量级)
* **大量数据越权/泄露**：可获取大量（**≥5000 条 且 <50W 条**）美团用户个人敏感信息、商户敏感信息的越权遍历与信息泄露风险（须满足 ≥3 字段组合且含 1 种标识）。

### 3. 水平越权敏感操作 (无前置条件)
* **无前置条件的高危越权**：
  * 账号越权修改他人重要信息；
  * 越权进行订单敏感操作；
  * 重要业务的重要配置修改等核心越权行为。

### 4. 核心页面存储 XSS
* **核心无交互 XSS**：美团首页、大众点评首页、门店首页、商品页面、活动页面中，**无需交互可直接攻击美团用户的存储型 XSS 风险**。

### 5. 账号体系劫持 (1-Click)
* **1-Click 账号接管**：用户点击攻击者构造的恶意链接后，**无需任何额外交互**（如扫码、二次确认等），攻击者即可直接获得目标账号完整控制权。

# 四、中危漏洞 (Medium)

### 1. 前端与交互安全
* **非核心页面无交互存储 XSS**：非高危指定范围页面的无需交互存储型 XSS（XSS 盲打类必须明确攻击触发点）。
* **核心页面反射 XSS**：美团、点评首页、门店首页、商品页面及活动页面中的反射型 XSS 风险。

### 2. 水平越权（普通操作 / 未达高危标）
* **非敏感与低量级越权**：
  * 越权查询/修改用户非敏感信息；
  * 越权查询商家流水、发票信息（含查询、新增、修改、删除操作）；
  * 越权查询订单号等非敏感功能越权；
  * 越权获取用户出行信息（如行程记录、位置轨迹），但未同时关联个人标识信息（如姓名、手机号、身份证号）；
  * 越权获取敏感信息，但**字段数量不足 3 个**，或**数据量 < 5000 条**；
  * 不满足高危标准的其他水平越权遍历风险。

### 3. 垂直越权敏感操作
* 垂直越权修改重要信息、进行订单普通操作、重要业务配置修改等。

### 4. 业务逻辑与流程设计缺陷
* 条件竞争漏洞 (Race Condition)。
* 前端校验绕过、认证流程绕过。
* 优惠券 / 优惠资格使用限制绕过（**【明确不包含】拉新活动**）。

### 5. 网络与普通泄露
* **无回显 SSRF**：能直接访问美团内网但无回显的 SSRF（须按规定完成连通性证明）。
* **代码平台泄露**：GitHub 等代码平台中涉及美团内部密码等问题的普通信息泄漏。

### 6. Click 类账号会话劫持
* **1-Click 会话劫持**：点击恶意链接无需额外交互即可触发会话劫持，但攻击者获得的权限有限，无法完整接管账号。
* **多步交互劫持**：点击链接后，仍需用户主动完成扫码、授权确认或按照特定业务流程执行方可触发的账号劫持。
* **社工配合泄露**：导致用户敏感信息泄露，但必须依赖一定社会工程学配合的场景。
* **【判定要求】**：报告必须完整还原攻击链路，并提供可稳定复现的 PoC。

# 五、低危漏洞 (Low)

### 1. 边缘前端安全
* 一般业务页面的反射型 XSS。
* 涉及用户敏感操作的 CSRF 风险。
* CORS 跨域配置缺陷导致的敏感信息泄漏风险。

### 2. 弱口令与暴力破解
* 美团用户或商家用户登录验证码、登录密码的暴力破解风险。

### 3. 轻微信息泄漏
* SVN 信息泄漏、调试 Debug 页面泄露、服务端配置信息泄漏。
* 客户端应用本地 SQL 注入（仅泄漏数据库名称、字段名、cache 缓存内容等）。
* 难以利用的 SQL 注入点（如无法提取数据）。

### 4. 其他低危项
* **无交互 URL 跳转**：无交互的任意 URL 跳转漏洞。
* **普通垂直越权**：用户普通功能的垂直越权访问。
* **高频短信轰炸**：对任意指定用户或手机号无限制的短信轰炸（**参考阈值门槛：30条 / 单手机号 / 分钟**）。

# 六、无效与不予收录 (Invalid / Out of Scope)

### 1. 不涉及安全的产品 Bug
* 功能逻辑缺陷、网页乱码、样式混乱、静态文件目录遍历、应用兼容性、复杂交互的 URL 重定向、账号存在性枚举。

### 2. 无法利用的理论问题
* **无敏感操作 CSRF**：收藏、取消收藏、添加购物车、一般资料修改等。
* **无凭据信息暴露**：无意义的异常报错、无意义源码泄露、内网 IP/域名泄漏、无敏感信息的越权访问、401 基础认证钓鱼。
* **无敏感跨域**：无敏感信息的 JSONP 劫持、无敏感信息的 CORS 跨域、Self-XSS、纯 JS/IMG 静态打包文件、无敏感 logcat。
* **本地文件解析风险**：浏览器本地解析 PDF 文件造成的 XSS 等风险。
* **未达标轰炸与拒绝服务**：邮箱轰炸、未达到 30条/分钟标准的短信轰炸、无法证明实际影响的 DOS 风险。

### 3. 主观猜测与无效扫描
* 纯属用户猜测、无法重现、未经验证的扫描器报告。

# 七、大模型相关产品漏洞收录评级标准

> **适用范围**：LongCat 大模型、美团各业务线 Agent 产品（餐饮助手、出行助手、外卖智能客服、IM 聊天机器人等）。

### 7.1 内容安全类处理原则
* **基本原则**：非信息安全漏洞引发的内容安全风险原则上不收录；与模型输入提示及输出响应内容直接相关的问题暂不收取。
* **【特批收录条件】**：若上述问题对产品造成**额外的、可直接验证的安全影响（机密性、完整性、可用性）**，按正常流程收录。
* **明确暂不收取的情形**：
  * **模型提示层**：越狱攻击 (Jailbreak)、安全机制绕过（如 DAN 类提示词注入等）。
  * **模型响应层**：模型输出违规内容（如违规营销话术、恶意代码片段等，走业务客服与反馈通道）。
  * **模型幻觉层**：诱导大模型模拟终端环境并执行伪指令等幻觉利用行为。

### 7.2 AI 服务风险边界
* 非隐私数据泄露类 AI 服务风险暂不收取（如 Prompt Leak 提示词泄露等）。
* **用户自定义 Agent 豁免**：由平台用户自行发布的业务 Agent 及其关联插件所引发的安全漏洞不予收取。

### 7.3 沙箱环境代码执行说明
* **预期功能声明**：沙箱环境中的代码执行 / 命令执行能力属于产品预期功能，默认不作为漏洞。
* **【有效漏洞判定条件】（满足任一即正常评分）**：
  1. **逃逸成功**：成功逃逸至宿主机 / 物理机层面；
  2. **提权凭证**：获取到有效的宿主敏感信息或提权凭据；
  3. **内网穿透**：可证明已穿透至美团内网环境（如借助 SSRF 连通性验证；若证明内网连锁影响，可进一步升级评级）。
